# Quran Companion – Mushaf pages

Page images (Madinah Mushaf, 1024 px wide, 604 pages) downloaded on demand by the
Quran Companion Android app, so the app itself stays small.

The files are attached to the `mushaf-1024-v1` release. Each one is checked by the
app against a SHA-256 manifest (`mushaf-1024.sha256`) before it is used.

Source: the King Fahd Glorious Qur'an Printing Complex Madinah Mushaf, as distributed
by Quran for Android (files.quran.app).
